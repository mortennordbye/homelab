How the homelab is built and run

Three Proxmox nodes run Genesis, a Talos Kubernetes cluster of six VMs. Terraform builds the machines and Argo CD reconciles everything else from the main branch of {{ config.repo_name }}. These pages explain how the parts fit together, and how to operate or rebuild each one.

What this is

A personal lab for self-hosted services and for trying infrastructure patterns that don't fit a day job: a portfolio and blog with stage and prod, a media stack, a few of my own apps, and the platform under them. The repository is public, and this is its documentation.

How it relates to the repo

Every page is a file in the repo's docs/ folder, published on each push to main. platform/ covers the shared infrastructure in k8s/talos/infra/ and terraform/, and apps/ covers workloads in k8s/talos/apps/ that need more than their manifests. Links to code open the file on GitHub. Where a page and the code disagree, the code is what runs and the page gets fixed.
