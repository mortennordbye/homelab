# ai/notes/

Research notes, benchmarks, decision records — anything written-down that isn't code.

## Conventions

- One topic per file. Filename = `YYYY-MM-DD-<slug>.md` for dated notes, or `<slug>.md` for evergreen references.
- Lead with a one-line summary so future-you can skim the folder.
- Link to the project / agent / skill the note relates to, when applicable.
- Outdated notes get deleted, not archived. Git history is the archive.
