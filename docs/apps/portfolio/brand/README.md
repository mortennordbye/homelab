# Portfolio brand

How `nordbye.it` looks, moves and presents content. Read these before proposing a design change.

- [decisions.md](decisions.md): the agreed record of what is locked, what was rejected and why,
  and what is still open.
- [art-direction.md](art-direction.md): the long-form rule book behind those decisions.
- [assets.md](assets.md): the asset shopping list, with verified licences and byte costs.

The shipped spec is `portfolio/src/content/brand.ts`, rendered at `/brand`. Where these documents
and the code disagree, the code is what the site does. The LinkedIn banner and its build script
live in [portfolio/branding/](../../../../portfolio/branding/README.md).
